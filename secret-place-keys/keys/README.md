# Keys

A key is a way to connect with the Father in the Secret Place — what to do when you don't know what else to do. Not what's revealed, just the door.

Examples: reading the Bible, singing and letting Him flow, asking Him a direct question ("what do You think of me?").

A "keys teaching" someday would be strictly about *how to connect* — nothing else.

Add entries as dated files, e.g. `2026-08-05-name-of-key.md`.

**Every key gets two things:** its own file (with full detail), and an entry in [The Key to Keys](2026-08-05-the-key-to-keys-master-list.md) — the running master list, organized by category, no duplicates, one line per key with a link back to its full file if there's more to it. Ask for "the key of keys" anytime to get the current master list to copy-paste.
